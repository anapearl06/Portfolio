EXP #001 LLM Structured Parser Benchmark +
QUESTION:

How does standard prompt instruction parsing compare to OpenAI JSON Schema Structured Output for nested JSON consistency?

TEST:

Ran 100 parallel resume parse calls: 50 parsing via textual markdown instructions ("Return JSON format") vs 50 utilizing strict JSON Schema parameters.

RESULT:

Text instructions failed on 8/50 outputs (malformed comma offsets or missing fields). Strict schema system completed 50/50 runs with zero structure violations.

CONCLUSION:

Strict structural schema is required when feeding model outputs to downstream database layers.

✓ VALIDATED
EXP #002 Vector Database Similarity Thresholds +
QUESTION:

What cosine similarity cutoff returns the most precise context chunk matches without capturing irrelevant noisy text nodes?

TEST:

Queried technical documentation logs adjusting thresholds from 0.5 to 0.85. Evaluated response accuracy on 20 QA runs.

RESULT:

Values under 0.65 pulled noisy paragraphs. Values above 0.80 skipped key snippets. Optimal threshold range resides at 0.72–0.75.

CONCLUSION:

Deploy query logic matching vector nodes inside the 0.73 boundary to maintain RAG coherence.

⚙️ ENGINEERING_PRINCIPLES.md
  1. 01
    Understand before implementing

    Define constraints, study system trade-offs, and sketch parameters before committing directories.

  2. 02
    Build before memorizing

    Synthesize syntax through practical execution. Active builds force authentic architectural debugging.

  3. 03
    Prefer simple architectures

    Avoid microservice layouts when a modular monolith handles requests. Reduce complexity surfaces.

  4. 04
    Design for failure

    Systems break. Wrap requests in timeouts, implement retries, and design offline fallback behaviors.

  5. 05
    Automate repetitive work

    Script boring steps, standard build tests, lint checks, and directory copies to guard focus.

  6. 06
    Document decisions

    Write explicit comments detailing "Why" a structure was written, not just "What" the syntax is.

  7. 07
    Measure before optimizing

    Profile processes, query logs, and payload boundaries before refactoring blocks for speed.
